# 🔢 Even Odd Number Checker

## 📌 About the Project
Number Checker is a beginner-friendly Python project that checks whether a number is positive, negative, or zero and determines whether it is even or odd.

The program also includes a replay option that allows users to check multiple numbers without restarting the program.

## ✨ Features
- Check whether a number is positive, negative, or zero.
- Determine whether a number is even or odd.
- Check multiple numbers in one session.
- Interactive yes/no replay option.
- Display clear and user-friendly messages.

## 🛠️ Technologies Used
- **Programming Language:** Python
- **Concepts Used:** Variables, user input, `if-elif-else`, `while` loop, modulo operator (`%`), and `break` statement.

- Using the modulo operator to identify even and odd numbers.
- Implementing loops to repeat a program.
- Using `break` to exit a loop.
- Taking interactive input from users.
